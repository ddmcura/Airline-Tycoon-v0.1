Airline Tycoon PH 1.0 playtest frontends

Use a Python environment compatible with Kivy 2.3.1 (verified here with
Python 3.12), then install requirements.txt and launch:

    python -m app.gui

The terminal developer/debug frontend remains available:

    python -m app.terminal

The GUI foundation supports career creation/load, runtime controls, read-only
fleet/flights/finance, manual save and bookmarks. Aircraft-market and weekly
scheduling GUI actions are planned for the next bounded gameplay slice.
